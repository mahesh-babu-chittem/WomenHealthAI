# Data Directory

The participant-level mcPHASES dataset is not included in this repository
because it is restricted study data.

Researchers wishing to reproduce the experiments should obtain authorized
access to the mcPHASES dataset through PhysioNet and place the locally
authorized files in the locations expected by the Stage 1 scripts.

The public repository contains only:

- Data-format documentation
- Expected input structure
- Clearly identified fictional examples where required
- Aggregate experimental results

No participant-level records, merged datasets, individual RHRS scores,
individual predictions, or participant-specific reports are distributed
through this repository.
