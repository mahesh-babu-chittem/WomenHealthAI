# 🔬 Stage 4 --- RHRS Validation

> **Purpose:** Evaluate the reliability and construct-related validity
> of the Reproductive Health Resilience Score (RHRS) generated in Stage
> 3.

Stage 4 evaluates the RHRS using four complementary analyses:

1.  Internal consistency / reliability
2.  Convergent validity
3.  Known-group validation
4.  Predictive validity

The validation pipeline operates on the Stage 3 RHRS dataset:

    data/processed/rhrs_dataset.csv

and writes all validation outputs to:

    results/stage4_validation/

# 🧮 4. Reliability Analysis

### Script

    reliability_analysis.py

### Purpose

Internal consistency is evaluated across the five RHRS dimensions:

    HRS
    PRS
    MRS
    BRS
    SRS

The implementation first extracts these five variables.

Cronbach's alpha is then calculated using:

    α =
    k/(k−1)
    ×
    [1 − Σσ²ᵢ / σ²ₜ]

where:

-   `k` = number of RHRS dimensions
-   `σ²ᵢ` = variance of dimension `i`
-   `σ²ₜ` = variance of the summed RHRS dimensions

The implementation uses:

    k = 5

The calculation is implemented directly in `reliability_analysis.py`.

### Output

    results/stage4_validation/reliability_results.json

and:

    results/stage4_validation/Table_11_Reliability.csv

The script writes the resulting Cronbach's alpha value to both formats.

### Interpretation

Cronbach's alpha evaluates the degree to which the five RHRS dimensions
exhibit internal consistency when treated as components of the composite
resilience construct.

For the implemented RHRS dimensions, the observed Cronbach's alpha is α
= 0.163. This indicates limited internal consistency among the five
dimensions and should be interpreted cautiously because RHRS is a
multidimensional composite index whose components represent distinct
physiological, reproductive, metabolic, behavioral, and symptom-related
dimensions.

It should be interpreted as a measure of internal consistency of the
implemented RHRS dimensions, rather than as evidence that RHRS is a
directly observed clinical latent variable.

The manuscript explicitly frames RHRS as a construct aligned with
measurable hormonal, physiological, metabolic, behavioral, and
symptom-related phenomena rather than a directly observed clinical
latent variable.

# 🔗 5. Convergent Validity

### Script

    convergent_validity.py

### Purpose

Convergent validity is assessed by measuring the association between
RHRS and health-related variables expected to relate to reproductive
resilience.

The implementation evaluates:

  Variable         Domain
  ---------------- ---------------------
  `sleep_score`    Sleep
  `mean_rmssd`     Physiological / HRV
  `stress_score`   Stress
  `lh`             Hormonal
  `estrogen`       Hormonal
  `pdg`            Hormonal

The script computes Pearson's correlation coefficient between each
variable and:

    RHRS

using:

    scipy.stats.pearsonr()

For each variable, the following are recorded:

-   Pearson correlation coefficient `r`
-   p-value

### Output

    results/stage4_validation/convergent_validity.json

and:

    results/stage4_validation/Table_12_Convergent_Validity.csv

### Expected Direction

Based on the RHRS formulation:

  Indicator      Expected relationship
  -------------- --------------------------------------------------------
  Sleep score    Positive
  RMSSD          Positive
  Stress score   Negative
  LH             Positive association under the implemented formulation
  Estrogen       Positive association under the implemented formulation
  PdG            Positive association under the implemented formulation

The sign and magnitude are determined empirically from the dataset.

No causal interpretation is made from these correlations.

------------------------------------------------------------------------

# 🧪 6. Known-Group Validation

### Script

    known_group_analysis.py

### Purpose

Known-group analysis evaluates whether observations with substantially
different RHRS values also demonstrate differences in selected
health-related variables.

The implementation defines two groups using the empirical RHRS
distribution.

### Low-RHRS group

Observations satisfying:

    RHRS ≤ 25th percentile

### High-RHRS group

Observations satisfying:

    RHRS ≥ 75th percentile

Thus, the analysis compares observations from the lower and upper
quartiles of the observed RHRS distribution.

The groups are not defined using arbitrary clinical thresholds.

------------------------------------------------------------------------

## Variables Tested

Four variables are compared between the high- and low-RHRS groups:

  Variable         Domain
  ---------------- ---------------------
  `sleep_score`    Sleep
  `mean_rmssd`     HRV / physiological
  `stress_score`   Stress
  `mean_glucose`   Metabolic

For each variable, the script applies an independent two-sample t-test:

    ttest_ind(
        high_group[col],
        low_group[col],
        nan_policy="omit"
    )

The resulting statistics are:

-   t-statistic
-   p-value

### Output

    results/stage4_validation/known_group_results.json

and:

    results/stage4_validation/Table_13_Known_Groups.csv

------------------------------------------------------------------------

# 🔮 7. Predictive Validity

### Script

    predictive_validity.py

### Purpose

The predictive-validity script evaluates the association between RHRS
and a composite symptom-burden measure.

The symptom burden is constructed from:

    headaches
    cramps
    fatigue
    foodcravings
    bloating

The implementation calculates:

    symptom_burden =
    mean(
        headaches,
        cramps,
        fatigue,
        foodcravings,
        bloating
    )

The Pearson correlation is then calculated between:

    RHRS

and:

    symptom_burden

using:

    scipy.stats.pearsonr()

The output contains:

-   correlation coefficient
-   p-value

### Output

    results/stage4_validation/predictive_validity.json

and:

    results/stage4_validation/Table_14_Predictive_Validity.csv

------------------------------------------------------------------------

# ⚠️ Important Reproducibility Note --- Predictive Validity

The current implementation calculates:

    corr(RHRS_t, SymptomBurden_t)

because both RHRS and symptom burden are taken from the same dataframe
row.

It does **not currently implement a temporal shift such as**:

    corr(RHRS_t, SymptomBurden_{t+H})

Therefore, this script currently evaluates an association between RHRS
and contemporaneous symptom burden.

The manuscript describes predictive validity as an association between
RHRS and **future symptom burden**.

This distinction should be preserved when reproducing the current code.

If a true future-symptom prediction analysis is required, the
implementation would need to explicitly construct a future
symptom-burden target using an appropriate temporal offset before
computing the correlation.

# 📊 12. Relationship Between Validation Tests

The four analyses address different aspects of the RHRS construct.

### Reliability

    Do the five RHRS dimensions exhibit internal consistency?

### Convergent validity

    Does RHRS associate with related physiological,
    hormonal, sleep, and stress indicators?

### Known-group validation

    Do observations at the upper and lower ends
    of the RHRS distribution differ in relevant
    health-related measurements?

### Predictive validity

    Does RHRS associate with symptom burden?

Together, these analyses provide complementary evidence rather than
representing four versions of the same statistical test.

------------------------------------------------------------------------

# ⚖️ 13. Statistical Interpretation

The Stage 4 analyses use statistical association and group-comparison
methods.

A statistically significant p-value should not by itself be interpreted
as evidence of:

-   causality,
-   clinical diagnosis,
-   treatment effectiveness,
-   universal clinical validity,
-   generalization to populations outside the study sample.

The present validation should therefore be interpreted within the
characteristics and limitations of the MCPHASES-derived dataset.

The manuscript itself identifies dataset size, population
characteristics, sampling bias, and measurement bias as limitations and
identifies external validation on larger and more diverse populations as
future work.

------------------------------------------------------------------------

# ⚠️ 14. Multiple-Comparison Consideration

The current Stage 4 scripts report the raw p-values produced by the
individual statistical tests.

They do not currently implement:

-   Bonferroni correction
-   Holm correction
-   Benjamini--Hochberg FDR
-   family-wise error control

Therefore, the reported p-values should be understood as **unadjusted
p-values** unless an additional multiple-comparison correction is
performed elsewhere.

This is intentionally documented here for reproducibility.

------------------------------------------------------------------------

# ⚠️ 15. Confidence Intervals

The current Stage 4 scripts report:

-   Pearson `r`
-   Pearson p-value
-   t-statistic
-   t-test p-value
-   Cronbach's alpha

They do not currently calculate confidence intervals for these
estimates.

Consequently, confidence intervals should not be claimed as outputs of
the present implementation unless they are generated by a separate
analysis script.

# 🔬 17. Reproducibility and Data Leakage

All Stage 4 analyses operate on:

    data/processed/rhrs_dataset.csv

The scripts do not perform model training.

The known-group analysis uses empirical RHRS quartiles calculated from
the supplied dataset.

The convergent-validity and predictive-validity analyses use Pearson
correlation.

The reliability analysis uses the five RHRS component scores.

Because these analyses are descriptive/validation analyses rather than
forecasting-model training, the scripts do not create a
train/validation/test split.

The chronological 70%--15%--15% split described in the manuscript
applies to the downstream temporal forecasting experiments rather than
to these Stage 4 validation scripts.

# 🧠 19. Important Interpretation of RHRS Validation

The RHRS should be interpreted as a computational composite resilience
index.

The validation analyses provide evidence regarding:

    internal consistency
            +
    associations with related measurements
            +
    differences between empirically defined RHRS groups
            +
    association with symptom burden

They do not establish that RHRS is a clinical diagnostic instrument.

The manuscript explicitly describes the construct as being aligned with
measurable hormonal, physiological, metabolic, behavioral, and
symptom-related phenomena rather than as a directly observed clinical
latent variable.
